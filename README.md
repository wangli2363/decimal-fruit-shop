# 小数水果铺

面向小学三年级的一位小数入门课堂资源。教师投影操作，学生口头解释并在学习单上作答。

- 任务一：解释2.3元，可切换完整画面、单位条与小数、只看小数。
- 任务二：比较同样苹果的2.3元和2.8元价格，先解释，再核对价差。
- 任务三：解释0.7米，分享生活中的小数与用途。
- 教师工具：课堂节奏、评价口径、常见误解追问和补充价签。

纯静态HTML、CSS、JavaScript与SVG插图；课堂没有实时AI请求。匿名代表例子仅在当前页面临时显示，不上传或持久保存。朗读依赖设备可用的本地中文语音。

页面与素材由AI辅助制作，正式教学前需教师复核。补充水果和价档默认收起；功能走查不等于学习成效证据。

使用GitHub Pages发布：选择main分支的根目录。所有网页资源采用相对路径，无需登录、无需API密钥。
